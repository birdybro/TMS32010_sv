# Engineering backlog

Statuses: `NOT STARTED`, `RESEARCHING`, `BLOCKED`, `IMPLEMENTING`, `VERIFYING`,
`COMPLETE`. A task reaches `COMPLETE` only after all acceptance criteria have
objective passing evidence.
