# Open architecture questions

Open questions are not implementation permissions. Provisional choices require
a targeted test and must retain their confidence label.

| OQ-003 | What value does `SST` produce in reserved bit 1? | RESOLVED_CORROBORATED: SPRU001B Figure 2-7 marks bit 1 “don't care,” but the original SST instruction page explicitly draws it as one. SPRU013 labels the SST position reserved, states that SST reads reserved status bits as ones, and its worked result `0x5efe` has bit 1 set. Pinned MAME independently forces the bit high before SST. The implementation stores one while documentation warns software that the position remains reserved; this is not a physical-mask measurement | original-part erratum or physical TMS32010 SST measurement only to upgrade confidence beyond CORROBORATED | possible context-save code that inspects the complete saved word |
| OQ-004 | What is the exact interrupt-recognition and vector-fetch cycle trace? | PARTIALLY RESOLVED_PRIMARY: SPRU001B Figure 2-12 establishes fetch N, fetch N+1, dummy fetch N+2, and fetch vector 2 beside execute N, execute N+1, dummy, and execute 2. Directed explicit-pipeline RTL retires one protected word while discarding N+2, performs entry with an empty execute slot while capturing vector 2, and executes the vector only in the following interval; stalls prove no early effects. MPY/MPYK protected-slot tests retain protection through one additional instruction, checking signed results, internal-read versus program-only bus shape, stalls, post-following dummy/return-PC ownership, and vector execution. Matching 32-case core and explicit-pipeline matrices exhaust active-low arrival at every represented execution interval of the 11 supported two-word control-flow families, IN, OUT, TBLR, and TBLW, with family-specific bus, completion, protected-instruction, dummy, stack, acknowledge, and vector assertions. A four-phase native test proves the digital wrapper samples a held-low request only at an enabled falling boundary, including a phase-2 stall. Physical setup/synchronizer behavior, provisional DINT cancellation ordering, and unsupported CALA/RET/PUSH/POP cycles remain unqualified | physical trace if setup/synchronizer behavior remains externally ambiguous after a proper CDC wrapper; primary or hardware evidence for DINT ordering and unsupported instruction cycles | low on A044427 Rev A because board INT is pulled inactive-high |
| OQ-005 | Is Hard Drivin' TMS32010 `INT` tied inactive, and what net is `PR1`? | RESOLVED_PRIMARY for production Rev-A drawing A044427: DSP pin 5 connects to `PR1`; sheet 1 pulls `PR1` inactive-high through `R26` (1 kΩ), no loaded active driver appears anywhere in the ten-sheet drawing, and the only switching option on sheet 7 is marked `NOT LOADED`. Pinned MAME independently configures BIO but no DSP interrupt source. Other board revisions have not been audited | audit another physical board revision only before claiming equivalence beyond A044427 Rev A | Rev-A wrapper defaults INT high/inactive while the generic core retains an external input |
| OQ-006 | Which edge completes reset and starts the first address-0 fetch? | RESOLVED_PRIMARY: recognized reset changes are synchronized to falling CLKOUT; PC/address clears after the next complete cycle, and release resumes after one complete cycle with address 0 then 1 | Appendix A reset timing, data-sheet p. 19 (PDF p. 375); directed RTL phase test passes | reset/halt release trace |
| OQ-007 | What are exact taken/untaken branch prefetch, execute-interval, and address traces? | PARTIALLY RESOLVED: TI establishes overlap, two words/two cycles, the following target operand, and ordinary program fetches, but no dedicated original-part branch/call pin waveform has been located. Exact `B`, `BANZ`, `BV`, `BIOZ`, `CALL`, and the six accumulator-conditional branches now have INFERRED explicit-pipeline mappings: opcode-prefetch completion enters execute ownership; PC+1 operand fetch is execution cycle 1; selected-instruction fetch is execution cycle 2; the branch/call retires as that word enters the execute slot. B always selects target. BANZ uses the old selected nine-bit counter to select target/fallthrough and defers its modulo-512 decrement until retirement. The accumulator family selects from the unchanged full 32-bit ACC and preserves it. BV selects from old sticky OV and clears it only at taken retirement. BIOZ samples raw active-low BIO at operand completion and retains the resulting decision, not an opcode-time pin latch, through the selected fetch. CALL selects the target unconditionally and pushes opcode-PC+2 only at selected-target capture. Directed tests cover every integrated condition, target/fallthrough selection, selected-fetch stalls, no early fetched-instruction effect, retirement-only mutations, nested CALL stack shifting, and malformed-operand parking. These combined commit mappings must not be called VERIFIED_PRIMARY. BIOZ's raw active-low sampling fact, CALL's stack/target effects, and all numeric totals remain primary-verified. CALA and RET are functionally/model-qualified as exact words `0x7f8c`/`0x7f8d` with documented state effects and two-cycle totals, but their second external cycles remain UNKNOWN | original TI branch/return control timing, development-system traces, or physical logic-analyzer captures; continue explicit integration one primary-defined family at a time under targeted tests | program trace alignment and interrupt-return timing |
